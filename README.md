## CN2 GIA、CN2 GT 和普通线路别混为一谈

“CN2”并不自动等于“CN2 GIA”。搬瓦工官网把 CN2 GT 与 CN2 GIA 分开说明，也将 GIA 描述为成本更高、用于中国方向网络质量的线路类型。具体购买时，应核对商品名称、机房和线路说明，而不是只凭第三方文章里的简称判断。

同样，套餐写着 2.5 Gbps 或 10 Gbps，也不等于每位用户都能持续跑满这个速率。端口规格是套餐参数，实际吞吐还会受到网络路径、目的地和使用时段等因素影响。挑 VPS 时，这些参数有参考价值，但不能替代实际业务测试。

## 选月付套餐时，优先看这几项

### 先确定机房，再看价格

洛杉矶、香港、日本和新加坡的机房位置不同。若你的访客主要在中国大陆，重点应放在目标运营商、实际路线和业务对延迟的容忍度，而不是只看哪档月费最低。搬瓦工官网将洛杉矶 USCA_9 作为其洛杉矶 CN2 GIA/CTGNet 方案之一，并说明支持机房迁移；迁移政策和可选机房仍应以具体产品页面为准。

### 按实际流量选，不要把峰值当月均

官网按月给出流量额度。个人项目、测试站或小流量服务可能用不到数 TB；图片、下载或较多访客则要留意流量消耗。带宽端口很大，不代表月流量无限。选购前最好估算访问量、文件大小和备份流量。

### 预留系统和维护空间

小配置并非不能运行网站，但系统本身、数据库、缓存和监控都会占资源。若要同时部署多个服务，RAM 与磁盘空间往往比单看 CPU 核数更值得优先核对。搬瓦工方案是 self-managed，自行维护是购买时需要计入的时间成本。官网列有 KiwiVM 管理面板、系统重装、控制台、快照和备份等功能，但这些并不等同于托管式运维服务。
